## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/c-practice.git
```

Compile any program using GCC:

```bash
gcc filename.c -o program
```

Run it:

**Windows**
```bash
program.exe
```

**Linux / macOS**
```bash
./program
```
